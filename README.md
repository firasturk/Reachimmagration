# Reach Immigration — الموقع

موقع ثنائي اللغة (`/en/` و `/ar/`) مبني بـ **Astro + TypeScript**: صفحات HTML ثابتة، وJavaScript بس وين لازم.

## التشغيل
```bash
npm install
npm run dev        # http://localhost:4321/en/
npm run build      # الناتج بمجلد dist/
```
## الرفع (GitHub ثم Vercel)
1. GitHub: مستودع جديد فاضي، وبعدين **uploading an existing file** واسحب كل محتويات هالمجلد (بدون `node_modules` و `dist`) واعمل Commit.
2. Vercel: **Add New → Project → Import** للمستودع، وبعدين **Deploy**. ما في إعدادات: `vercel.json` محدد Astro، و`package.json` محدد Node 22 (Astro 7 بده 22.12 أو أحدث).
3. بعد أول رفع: حط `CRM_WEBHOOK_URL` بـ Settings → Environment Variables عشان الفورم يبعت، واربط الدومين.

أي push جديد على GitHub بينشر لحاله.

## لازم ينعمل قبل الإطلاق
1. **الفورم:** حط `CRM_WEBHOOK_URL` بإعدادات Vercel. بدونه الدالة بترجع 501 عن قصد.
2. **اللوجو:** هلأ كلمة REACH مكتوبة. بدنا SVG الأبيض والغامق، وكود الخمري الرسمي (`--brand-accent` بـ `src/styles/global.css`).
2ب. **خط GE Dinar Two:** الـ CSS جاهز، بس الخط تجاري ومش مرفق. لازم ملفات WOFF2 المرخّصة تنحط بـ `public/fonts/` بالأسماء المذكورة بالـ README هناك. لحد وقتها العناوين العربية بتطلع بخط El Messiri (وبتظهر أخطاء 404 للخط بالكونسول، طبيعية).
3. **مراجعة العميل لأرقام البرامج:** صفحات البرامج العشرين مكتوبة كاملة بـ `src/data/programs/` بأرقام إرشادية بتاريخ سبتمبر 2026 (والتاريخ مطبوع على الصفحة). لازم العميل يمرّ عليها ويأكد المبالغ والمدد قبل الإطلاق، وأي تعديل بيصير من نفس الملفات.
4. **بيانات التواصل:** عناوين وهواتف الـ 17 فرع بـ `branches` في `src/data/site.ts` مأخوذة من صفحة التواصل بموقعهم الحالي ومن قوائم الوكلاء الرسمية (سبتمبر 2026). رقم الواتساب مفترض إنه موبايل المقر الرئيسي (`+962 79 063 1087`) ولازم يتأكد. إيميلات الفروع محطوطة بس للفروع اللي بتنشر إيميل.
5. **قصص العملاء:** `stories` بـ `src/data/site.ts` فاضية. بتنحط حرفياً من نصوص العميل المعتمدة. حالياً القسم بيبيّن تقييم Google بس.
6. **تصنيف البرامج** (جنسية / إقامة) مأخوذ من روابط موقعهم الحالي، ولازم العميل يأكده (تركيا مثلاً مصنّفة إقامة بس صفحتها بتشرح الجنسية كمان). كمان الأرقام: +25 سنة، 20 وجهة، 17 فرع، 6 تراخيص، 5.0 على Google، +80 مستشار.
7. **المدونة والنشرة والتقييمات:** روابط المقالات بالرئيسية وروابط Blog/Reviews بالفوتر بتروح لموقعهم الحالي (`reachimmigration.com/en/blog/…`). إذا الموقع الجديد رح يستبدل الدومين نفسه، لازم يا إما تنقل المدونة (WordPress) على subdomain زي `blog.reachimmigration.com` ويتعدّل `insights` و `SITE.blogUrl` و `SITE.reviewsUrl`، أو تنبني صفحات مدونة بالموقع الجديد. **بدون هالقرار الروابط رح تنكسر يوم الإطلاق.**
8. **أداة التقييم** من الموقع القديم بدّلها الفورم الذكي (تحويل 301 لصفحة التواصل). مؤشر الجوازات معاد بناؤه على نفس الرابط القديم.
9. **صور البلدان:** كروت الخريطة وصفحات البرامج بدون صور خاصة بكل بلد. لما تتوفر بتنحط بـ `public/images/programs/<slug>.webp`.
10. الفيديوهات 720p. للشاشات الكبيرة الأحسن نسخ 1080p بنفس الأسماء بـ `public/video/`.
11. **الهيرو:** خلفية المشهد الثاني (`public/video/hero-bg.mp4` و`still-5.jpg`) لسا فيها نظارة الـ VR من الثيم. بدها فيديو أو صورة بديلة من العميل.

## الألوان
كلها توكنز بأول `src/styles/global.css`:
- **الخمري مهدّى:** نفس درجة لون الهيرو بس مخلوطة برمادي الثيم (تشبّع أقل بحوالي الربع)، فبتقرأ كنبيذ معتّق مش دموي. الدرجات: `--wine-900` · `--wine-700` · `--wine-600` (الأزرار) · `--wine-500` (النصوص والوسوم) · `--wine-400` · `--wine-300` · `--wine-100` و `--wine-050`. الخمري الأصلي الحاد محفوظ بـ `--wine-pure` للمسات الصغيرة إذا احتجناه.
- **رمادي الثيم:** `--slate-700` (خلفية ثيم 04) · `--slate-500` · `--slate-300` · `--slate-100`، مع `--mist` (أرضية الجواز) و `--ivory`.
- **درجات الأقسام** بكلاس واحد: `tone-ivory` / `tone-mist` / `tone-deep`. تبديل درجة قسم = تبديل الكلاس.
- ألوان الكرة الأرضية بتنقرأ من نفس التوكنز بـ `src/scripts/map.ts`، فما بتنفصل عن الموقع.

## ملاحظات
- كاروسيل الخريطة بيقلب لحاله كل 4.2 ثانية، وبيوقف نهائياً أول ما الزائر يلمس أو يسحب أو يكبس (مع `prefers-reduced-motion` ما بيشتغل أصلاً). الدوّارة الصغيرة جنب `Drag to rotate` بتبيّن الوقت المتبقي.
- الحركة: نفس الـ spring تبع الهيرو (`--spring`) لكل الموقع، ومع `prefers-reduced-motion` بتنطفي.
- بدون JavaScript: المحتوى كله ظاهر والفورم بيشتغل كصفحة وحدة.
- الفحص انعمل على Chrome (ديسكتوب ومحاكاة موبايل). لسا ما انفحص على Safari/iPhone حقيقي.
